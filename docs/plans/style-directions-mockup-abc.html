Direction BBrutalist

Thick ink outlines, hard offset shadows, flat colour blocks, a sticker. Everything looks like a physical object you could pick up, which suits a site whose product is a card. It is playful without being cute, and it photographs well in a screenshot because every element carries its own border. Team colour is a block, not a tint.
