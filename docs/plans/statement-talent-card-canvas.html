What this is. A real drawStatementTalentCard(D) that returns a canvas, written in the same conventions as the live card functions in src/pages/stats/player/[slug].astro: a define-vars-shaped D payload, shared ink and red constants, rrect and loadImg helpers, 2× scale, Barlow Condensed for numerals and headlines, JetBrains Mono for every number and frame label, and null-safe fallbacks that fail loud. The headshot and the multi-year shot map load from the same URLs the live card uses; if either is blocked, the card draws a labelled fallback instead of a hole.

What is real. Every number comes from the repo's src/data/stats/players.json for Jack Hughes: Talent (this snapshot carries the rating lineage, so it reads the rating percentile where hgb_talent_v1_percentile is absent), TOI/G, the eleven talent bars, WAR percentile computed against the 468 qualified forwards in the file, and Impact rank. Prior-season WAR is not in this snapshot, so the strip shows the one season it has and fills the other cells with real Impact and power-play values rather than inventing history.
