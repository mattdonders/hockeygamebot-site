HGB/Wire

A design direction for hockeygamebot.com. The premise: this is a wire service that happens to have a stats archive — not an archive that happens to post.

Sample data
The premise

Lead with the wire

The bots came first. This direction puts their output on the front page as a live dispatch column instead of burying it behind nav.

The mechanic

One token layer

Every colour below resolves from a single set of custom properties — the five competing :root blocks collapse into one.

The rule

Numbers wear mono

Condensed for names and scores, mono with tabular figures for every value. Already your brand rule; here it is enforced structurally.
